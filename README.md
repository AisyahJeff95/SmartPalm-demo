# SmartPalm Demo

Precision Agriculture Platform for Oil Palm Nutrient Analytics (N, P, K, Mg, Ca, B) powered by Sentinel-1 & Sentinel-2 Satellite Remote Sensing and Machine Learning.

- **Web Dashboard**: Interactive Leaflet geospatial heatmaps and block statistics.
- **Backend**: Python Flask prediction engine serving 10m GeoTIFF rasters and summary analytics.
