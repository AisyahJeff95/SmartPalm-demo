2. ENGINEERED FEATURES (21 INDICES ADDED TO THE 18 RAW BANDS = 39 TOTAL)
--------------------------------------------------------------------------------------------
Note: Sentinel-2 L2A bands (PB >= 04.00) include a +0.10 radiometric offset. Before
computing normalized ratios, SpectralFeatureEngineer subtracts 0.10 (clipped >= 1e-6)
so vegetation indices recover true physical surface-reflectance dynamic range.

  A. Optical Vegetation, Chlorophyll, Red-Edge & Moisture Indices (16):
     1. NDVI       = (B8 - B4) / (B8 + B4)             [Canopy vigor / biomass]
     2. NDRE1      = (B8 - B5) / (B8 + B5)             [Red-Edge 1 chlorophyll / N]
     3. NDRE2      = (B8 - B6) / (B8 + B6)             [Red-Edge 2 chlorophyll / N]
     4. NDRE3      = (B8 - B7) / (B8 + B7)             [Red-Edge 3 canopy structure]
     5. NDRE_8A5   = (B8A - B5) / (B8A + B5)           [Narrow NIR Red-Edge (N, Mg)]
     6. CI_RE      = (B7 / B5) - 1                     [Chlorophyll Index Red-Edge]
     7. CI_G       = (B7 / B3) - 1                     [Chlorophyll Index Green]
     8. GNDVI      = (B8 - B3) / (B8 + B3)             [Green NDVI / foliar N]
     9. NDMI       = (B8A - B11) / (B8A + B11)         [Canopy moisture / K & P stress]
    10. NBR        = (B8A - B12) / (B8A + B12)         [SWIR2 canopy dryness / Mg]
    11. SWIR_ratio = B11 / B12                         [SWIR1/SWIR2 biochemical ratio]
    12. SAVI       = 1.5 * (B8 - B4) / (B8 + B4 + 0.5) [Soil-Adjusted Veg Index]
    13. EVI        = 2.5 * (B8 - B4) / (B8 + 6*B4 - 7.5*B2 + 1) [Enhanced Veg Index]
    14. MCARI      = ((B5 - B4) - 0.2*(B5 - B3)) * (B5 / B4)    [Chlorophyll absorption]
    15. BG_ratio   = B2 / B3                           [Blue/Green pigment balance]
    16. RE_slope   = (B7 - B5) / B6                    [Red-Edge inflection slope]

  B. Sentinel-1 SAR Structural & Polarimetric Indices (5):
    17. VH_VV_ratio = Sigma0_VH / Sigma0_VV            [Cross/co-pol canopy density]
    18. RVI_SAR     = 4 * Sigma0_VH / (VV + VH)        [Radar Vegetation Index]
    19. Sigma0_VV_dB = 10 * log10(Sigma0_VV)           [Log VV backscatter (dB)]
    20. Sigma0_VH_dB = 10 * log10(Sigma0_VH)           [Log VH backscatter (dB)]
    21. Pol_Diff_dB  = Sigma0_VH_dB - Sigma0_VV_dB     [Polarization diff (dB)]
